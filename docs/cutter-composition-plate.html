The eight cutters are not eight independent gestures. They are four radii, each used exactly twice — and each pair enters the cube through the same wall. Two cutters per vertical wall, zero on floor and ceiling. Solid line = sphere (stamped), dashed line = cylinder (dragged through). Vermilion is reserved for the analysis overlays.
