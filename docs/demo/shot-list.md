# Cuboid Studio — One-Off Demo Recording: Shot List & Cue Card

The master plan: record the **live app** (cuboidstudio.vercel.app, signed in, network on)
in **8 short clips — one per narration beat**. Each clip is trimmed and laid against the
ElevenLabs narration (4:08) in editing. One recording session produces four deliverables:

| Deliverable | What it is |
|---|---|
| a. Friends & colleagues | Master cut with narration audio |
| b. Onboarding explainer | The same step clips, reusable with captions / UI callouts |
| c. Presentation embed | Silent master cut (talk over it live) |
| d. AI video editors | The clean per-step clips as source footage |

## Golden rules

1. **Record each clip LONGER than its slot.** Move slowly, let things breathe.
   Editing can only cut, never stretch. If a network step is slow, keep recording —
   the wait gets cut.
2. **Pause ~2 seconds at the start and end of every clip**, hands off the mouse.
   That's the trim margin.
3. **Flub something? Just re-record that one clip.** That's the whole point of segments.
4. Move the mouse **deliberately** — point, rest, then click. Fast cursor = unwatchable.

## Before you hit record (one-time prep)

- [ ] Do Not Disturb ON (Mac notifications will ruin takes)
- [ ] Clean browser window: hide bookmarks bar, close other tabs, 100% zoom
- [ ] Signed in to the app; at least one project with saved compositions
- [ ] The address you'll type in Map — decided in advance
- [ ] 2–3 photos of an inhabited space in a Desktop folder, ready to upload
- [ ] Browse the meme library beforehand and know WHICH meme you'll pick
- [ ] One silent dry-run of the whole flow before recording anything
- [ ] QuickTime → File → New Screen Recording → record the browser window
      (full screen of a 16:9 display is ideal; Retina is fine)

## The clips

Times = where the clip lands against the narration. Record 1.5–2× longer than the slot.

### Clip 1 — Opening · slot 0:00–0:24 (~25 s)
**Screen:** Map tab, empty map.
**Do:** Sit on the open Map tab. One slow, gentle map pan. Nothing else.
**Narration underneath:** "Every design tool you work with begins from the same substrate…"

### Clip 2 — Site · slot 0:24–0:59 (~35 s)
**Screen:** Address search → radius → POI layers.
**Do:** Type the address, pick the radius, let the POI categories populate. If the
visual project map ("My sites") is live by recording day, one glance at it here.
**Narration:** "We start with a site… written into a persistent site record…"
**Tip:** If analysis takes a while, keep rolling — the wait gets cut.

### Clip 3 — Encode + photo-save · slot 0:59–1:41 (~42 s)
**Screen:** Photo upload → five-axis reading → edit one axis → save.
**Do:** Upload the primary photo (+1–2 supplementary), run Encode, let the five-axis
reading appear, visibly adjust ONE axis (that's the "you can overrule it" money shot),
then **Save to project** — showing the photo thumbnail landing in the saved composition.
**Narration:** "Before the system commits to any geometry, it publishes its reading…"

### Clip 4 — Vocabulary + section cuts · slot 1:41–2:16 (~35 s)
**Screen:** assembly editor with the proposed/loaded assembly.
**Do:** Open the variation picker briefly (the 70-cube vocabulary), place or nudge a
cube, then run a **section cut** slowly through the assembly and back. End on a short orbit.
**Narration:** "Everything is built from one vocabulary: seventy cube variations…"

### Clip 5 — Pataphysical · slot 2:16–3:11 (~56 s, the longest beat)
**Screen:** Evolution tab → Pataphysical → meme → two-pass result.
**Do:** Switch to Evolution, enter Pataphysical, pick your pre-chosen meme, run
Translate. Let the two-pass result render; hover the confidence vector; tweak one
parameter; Apply. Slow down here — the narration gives you almost a full minute.
**Narration:** "Now the cultural material… Nothing between the joke and the cut is a black box."

### Clip 6 — Evolve · slot 3:11–3:35 (~23 s)
**Screen:** Candidate list, preview highlight, sparkline.
**Do:** Generate candidates, hover one so the amber preview highlight shows in the
viewport, apply one. Short beat — don't linger.
**Narration:** "Evolve generates a pool of candidate translations…"

### Clip 7 — Decode · slot 3:35–3:51 (~16 s)
**Screen:** Decode canvas.
**Do:** Place two or three tile glyphs, rotate one, snap to grid, open the SVG/DXF
export. Shortest beat of all.
**Narration:** "Finally, Decode… decoding is authorship too."

### Clip 8 — Close · slot 3:51–4:08 (~17 s)
**Screen:** The finished assembly.
**Do:** Back to the viewport; one slow, complete orbit of the final assembly. Hold.
**Narration:** "At no point did the system replace judgment…"

## After recording

Name the files `clip1-opening.mov` … `clip8-close.mov` and hand them over (GitHub
release upload works for big files). Assembly is then mechanical: trim each clip to
its slot, lay the narration under the master, export the silent version, keep the
per-clip files for onboarding and the AI editors.
